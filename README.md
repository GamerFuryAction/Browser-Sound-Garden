# browser-sound-garden 🌻🎵

hi! this is a simple interactive web project i made. every time you click anywhere on the page, a cute flower grows and it plays a sound!

### how it works:
* **left to right:** controls the pitch (left side is super low/bassy, right side is high pitch)
* **up to down:** controls the volume (clicking near the top is loud, clicking near the bottom is super quiet)

### tech stuff used:
* HTML5
* CSS animations (for the cute growing pop effect)
* Vanilla JavaScript + Web Audio API (no external libraries needed, keeping it lightweight!)
